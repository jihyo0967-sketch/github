# 그린빌드 AI - 친환경 건축 설계 도우미

고등학교 인공지능 기초 수업용 정적 웹 프로토타입입니다.

## 실행 방법
- `index.html` 파일을 브라우저에서 열면 바로 실행됩니다.
- GitHub Pages에 배포하려면 이 저장소의 루트(root)에 `index.html`을 올립니다.
- GitHub 저장소에서 **Settings → Pages → Deploy from a branch → main → /(root) → Save**를 선택합니다.

## 기능
- 지역 기후 유형, 건물 종류, 연면적, 층수, 예산, 설계 우선순위 입력
- 입력 조건에 따른 친환경·에너지 절약·접근성 설계 방향 제안
- 주요 고려 요소를 5점 척도의 참고 점수로 표시

## 데이터 및 AI 관련 안내
이 웹페이지는 입력값과 사전에 작성한 규칙을 이용하는 **규칙 기반 시제품**입니다. DataNet 국가건물에너지 통합DB에 직접 연결되어 있지 않으며, 해당 데이터로 학습된 기계학습 모델도 아닙니다. 실제 DataNet 데이터를 사용하려면 내려받은 데이터의 항목명·단위·기간·건물 유형을 확인하고, 이를 처리하는 별도의 데이터 분석 및 모델/API 연결 과정이 필요합니다.

화면에 표시되는 점수는 실제 건물 성능 예측값이 아닌 서비스 흐름을 보여주기 위한 예시 점수입니다.
